用 moonlight 串流之后，有时希望把手机，ipad 当做拓展屏幕，而不仅仅是复制，方法之一网购一个显卡欺骗器，这里通过程序模拟处 usb 适配器

## 构造虚拟屏

### 用 usbmmidd_v2

- 参考 [Win10/11 如何开启 第二屏幕/副屏/虚拟显示器，让平板成为副屏 - 知乎 (zhihu.com)](https://zhuanlan.zhihu.com/p/488465676?utm_id=0)
- 下载解压 usbmmidd_v2 到任意位置
- 以管理员身份打开 CMD
- 重定向至刚刚解压的文件夹内

```
cd C:\Users\Qttao\Download\usbmmidd_v2
```

- 安装

```
deviceinstaller64 install usbmmidd.inf usbmmidd
```

- 添加显示器

```
deviceinstaller64 enableidd 1
```

- 去除显示器

```
deviceinstaller64 enableidd 0
```

- 完全删除驱动

```
deviceinstaller64 stop usbmmidd

deviceinstaller64 remove usbmmid
```

## 虚拟屏及其应用

> 不必外界显示器也能运行串流

注意 moonlight 等串流软件通常需要电脑保持显示器开启，如果希望电脑不插显示器串流，或者熄屏状态下串流，则可模拟出显示器，然后将虚拟现实器串流。

> 平板手机当拓展屏

## 常见问题

> 拓展屏上鼠标消失

在系统设置打开显示指针轨迹即可
